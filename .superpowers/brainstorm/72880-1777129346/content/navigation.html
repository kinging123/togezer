│ ├─ habits/[id].tsx ← habit detail — pushed, covers tab bar
│ └─ check-in/[habitId].tsx ← modal sheet
app/index.tsx — routing guard (runs on every cold open)
export default function Guard() {
  const { isSignedIn, isLoaded } = useAuth()
  const { hasHabit }             = useHasHabit() // React Query

  if (!isLoaded) return <Splash />

  if (!isSignedIn)
    return <Redirect href="/(auth)" />

  if (!hasHabit)
    return <Redirect href="/(onboarding)/pick-habit" />

  return <Redirect href="/(app)" />
}
Check-in is a modal, not a tab
Launched from a habit card on Today or from the You tab. Defined as check-in/[habitId] inside (app) with presentation: 'modal'. Dismissing always returns to the previous tab.
Habit detail covers the tab bar
habits/[id] lives in the (app) Stack, not inside a tab. Pushing it covers the tab bar entirely — correct for a focused detail + history view.
Onboarding is its own group
Keeps the auth screens clean. The guard routes there if the user is signed in but has no habit yet. Re-entering the app after completing onboarding just skips past it.
Tab bar: Today · Friends · You
Matches wireframe Home_B/C. "Today" is the default tab. No check-in tab — the check-in action lives on habit cards, keeping the bar minimal.
